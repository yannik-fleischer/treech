# Treech

Treech is a Python library developed to support the construction and investigation of decision trees in educational settings.

## Research context

The library was developed as a technological resource for teaching predictive modeling with data-based decision trees in secondary education. It was used in conjunction with Jupyter notebooks as part of an instructional design investigated in the context of a cumulative doctoral dissertation at Paderborn University.

## Scope

This repository makes the source code available for scientific transparency and documentation of the instructional design. It is not intended as a maintained general-purpose software package. Compatibility with current Python environments is not guaranteed.
